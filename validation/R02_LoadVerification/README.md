# Case A R02 Load Verification

This folder contains the complete numerical export supplied
for independent verification of the Case A R02 shell mesh.

Contents include:
- Nodal coordinates
- SHELL281 element connectivity
- Boundary edge data
- Boundary traction summaries
- Restraint node information
- Element geometry and region data
- MATLAB verification script
- Solver input and metadata

The verification script checks external pressure and
boundary traction force and moment equilibrium.

This is not a structural FEA solution.
