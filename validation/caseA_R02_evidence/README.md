# Case A R02 — Preliminary ANSYS Evidence

This folder contains the initial static structural FEA
results and verification evidence for Case A R02.

Software: ANSYS Mechanical 2025 R1
Model: Intact curved fuselage panel
Benchmark pressure: 0.055 MPa (55 kPa), outward
Reference surface: Shell midsurface

## Preliminary results

- Maximum total deformation: 0.8999 mm
- Average von Mises stress: 47.627 MPa
- Average maximum principal stress: 54.997 MPa
- Average middle principal stress: 27.500 MPa

## Validation status

The initial solution agrees closely with analytical
thin-cylinder stress benchmarks.

Support stability, restraint-location sensitivity and
physical inner-face pressure verification remain pending.

This is a preliminary educational FEA result, not a
certified aircraft structural safety assessment.
