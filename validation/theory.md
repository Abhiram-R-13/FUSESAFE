## Preliminary stress threshold

The current team-selected provisional yield strength is 290 MPa, matching the latest ANSYS material entry:

`AA2024_T3_Bare_Provisional`

For a required FoS of 2:

\[
\text{Preliminary allowable stress}
=\frac{\text{Yield strength}}{\text{Required FoS}}
=\frac{290}{2}
=145\text{ MPa}
\]

The older 345 MPa value comes from a generic supplier reference and is retained as historical material data. It is not the current FUSESAFE modelling input.

The 290 MPa value is a team-selected provisional modelling assumption, not a certified sheet-specific design allowable.

This threshold is for educational stress screening only. It does not establish aircraft structural safety.
